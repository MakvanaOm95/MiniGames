Sudoku

Puzzle About 5+ min

Move with ← ↑ → ↓, type 1–9, and use Backspace to erase. Esc pauses. Tap a square, then tap a number below the board.

About Sudoku

Sudoku is a logic puzzle played on a 9×9 grid divided into nine 3×3 boxes. Some squares start with numbers. Your job is to fill in the rest so that every row, every column and every box contains the numbers 1 to 9 exactly once. No maths is needed, just careful thinking.

Every game on Tiny Tock is a brand-new puzzle, generated just for you and checked to make sure it has exactly one correct solution. Wrong numbers turn red so you can fix them straight away, and the timer tracks your fastest solve.

How to play

  1. Press Play to get a fresh puzzle. The timer starts.
  2. Select an empty square by tapping it or using the arrow keys.
  3. Enter a number with the number pad or your keyboard. The row, column and box light up to help you check.
  4. Fill every square correctly to finish. Your best (fastest) time is saved.

Tips to score higher

  • Start with the busiest areas. Rows, columns or boxes that already have many numbers are the easiest to finish.
  • Scan for one number at a time. Pick a number, like 5, and check each box for where it can go. Often there’s only one spot.
  • Look for “only one fits”. If a square can only be one number because the other eight are already in its row, column or box, fill it in.
  • Use the highlights. When you select a number, matching numbers glow. That makes it easy to see where it can’t go.
  • Don’t guess. Every puzzle can be solved by logic. If you’re stuck, scan a different number or box.
